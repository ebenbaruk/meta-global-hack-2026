# Meta Global AI Developer Hackathon — key info

- Hosts: Meta x Cerebral Valley — remote, worldwide
- **Submission deadline: Nov 4, 9:00 PM ET (Nov 5, 03:00 Paris)**
- Judging: Nov 4–8 · Closing ceremony / finals: Nov 9
- Prize pool: $1,000,000 across two tracks (one track per project)
  - Indie (solo builders, students): creativity, technical ambition, does it work
  - Startup (teams, founders): technical execution, production-readiness
- Themes:
  - Build for Your World — bring Meta models into a domain you know firsthand
  - Push the Frontier — software, robotics, manufacturing, energy, materials…
- Tech: Muse Spark series, Muse Wonder, Muse Image, SAM 3.1 via Meta Model API; Meta open-weights models; Muse Code agent
